2. **현장 소개** — 6호 신규 모델하우스(구경하는 집) 운영, 2·3·4·5·15호 분양 완료
3. **특장점 6** — 철근콘크리트 / 다락 11평+테라스 / 마당·루프탑 / 벙커주차 / 지중화·도시가스 / 조망
4. **타입 안내** — A타입 34평+다락 11평=실사용 45평, B타입 40평+다락 11평=실사용 51평
5. **갤러리** — 실사 6장(외관 · 거실 · 주방 · 마당/테라스 · 루프탑 · 다락), 클릭 시 라이트박스
6. **입지** — 보평역 도보 5~7분, 성산초 도보 통학, 경안천 수변공원, 용인IC 5분, 반도체 클러스터 15분, 보평3지구 고시(2026. 4.) + 네이버·카카오 지도 링크
7. **분양 현황** — 1~17호 그리드. 2·3·4·5·15호 분양 완료, 6호 모델하우스, 나머지 상담 문의
8. **채널** — 유튜브 2개(`텔루체타운하우스`, `용인 고림동 텔루체`) · 블로그 2개(`teluceyongin`, `yummyapt`)
9. **방문 예약** — 달력(지난 날짜 비활성) + 시간대 9개 + 방문 목적/성함/연락처 → 문자 예약(`sms:`) · 전화 · 내용 복사
10. **사업 주체** — 시행·토지주 직접 진행 `주식회사 영운`, 분양·개발 파트너 `하우스링`
11. **상담 · 푸터** — 대표번호, 주소, 홈 링크, 유의 문구
